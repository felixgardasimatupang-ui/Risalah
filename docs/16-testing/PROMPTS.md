# Prompts — Phase 16 Testing

## Menulis Test
```
Bantu menulis test untuk aplikasi AI Notulen Pemerintahan.

1. Unit Test (pytest):
   - Test semua service functions
   - Test semua API endpoints
   - Mock external services (AI, storage)

2. Integration Test:
   - Test database CRUD
   - Test queue processing
   - Test file upload flow

3. E2E Test (Playwright):
   - Login → Upload → View Transcript
   - Search → View Minutes → Export

4. AI Accuracy:
   - WER (Word Error Rate) test
   - DER (Diarization Error Rate) test
   - Test dengan dataset bahasa Indonesia
```
