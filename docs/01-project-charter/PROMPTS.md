# Prompts — Phase 01 Project Charter

## Menyusun Project Charter
```
Bantu menyusun Project Charter untuk proyek AI Audio-to-Text 
dan Notulen Pemerintahan Indonesia. Sertakan:

1. Visi & Misi
2. Business Goal (efisiensi, akurasi, adopsi)
3. Success Criteria (KPI teknis & bisnis)
4. Stakeholder map
5. Risk register (teknis, keamanan, adopsi)

Gunakan template PMBOK Project Charter.
```
