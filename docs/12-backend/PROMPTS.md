# Prompts — Phase 12 Backend

## Implementasi Backend
```
Bantu implementasi backend FastAPI untuk modul berikut:

1. Auth — JWT authentication, RBAC, MFA
2. Upload — menerima file audio, validasi format (MP3, WAV, M4A), chunking
3. Splitter — VAD-based audio splitting menggunakan Silero VAD
4. Queue — task queue dengan Celery + Redis
5. Transcript — CRUD API untuk hasil transkripsi
6. Speaker — kelola speaker mapping
7. Minutes — AI-generated notulen
8. Search — semantic search dengan vector embedding
9. Export — export ke PDF, DOCX, TXT

Gunakan FastAPI, SQLAlchemy, Celery.
Buat endpoint RESTful dengan dokumentasi OpenAPI.
```
