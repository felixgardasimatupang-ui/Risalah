# Prompts — Phase 03 PRD

## Menyusun PRD
```
Bantu menyusun Product Requirements Document untuk aplikasi
AI Notulen Pemerintahan. Sertakan:

1. User Persona (min 3)
2. Functional Requirements (fitur-fitur)
3. Non-Functional Requirements (performa, keamanan)
4. Use Case (UC-001 s.d. UC-010)
5. User Story format: "Sebagai [peran], saya ingin [fitur]"
6. Acceptance Criteria per user story
7. Success Metrics (akurasi, waktu, NPS)
8. Out of Scope

Gunakan format AI PRD Generator.
```
