# Prompts — Phase 17 Security

## Implementasi Keamanan
```
Bantu implementasi keamanan untuk aplikasi AI Notulen Pemerintahan.

1. JWT Authentication:
   - Access token (15 menit) + Refresh token (7 hari)
   - HTTP-only cookie
   - Token rotation

2. RBAC:
   - Roles: Super Admin, Admin, Editor, Viewer
   - Permission per resource

3. MFA:
   - TOTP (Google Authenticator)
   - Backup codes

4. Audit Log:
   - Log semua operasi CRUD
   - Log login attempts
   - Immutable log storage

5. Encryption:
   - AES-256-GCM untuk file audio
   - TLS 1.3 untuk transport
   - Environment-based secrets

6. OWASP Top 10 review
```
