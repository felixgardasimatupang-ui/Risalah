# Prompts — Phase 04 SRS

## Menyusun SRS
```
Bantu menyusun Software Requirements Specification untuk
aplikasi AI Notulen Pemerintahan. Sertakan:

1. Software Scope — fitur in-scope dan out-of-scope
2. API Requirements — endpoint, method, request/response
3. Data Requirements — entity, relationship, storage
4. Performance Requirements — response time, concurrency
5. Security Requirements — auth, RBAC, encryption
6. Compliance Requirements — peraturan perundangan

Gunakan standar IEEE 830.
```
