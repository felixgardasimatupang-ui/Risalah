# Phase 05 — Work Breakdown Structure (WBS)

**Tujuan:** Breakdown seluruh pekerjaan menjadi unit yang dapat dikelola.

**Struktur:**
1. Project Management — Planning, Review, Risk
2. Frontend — UI/UX, components, pages
3. Backend — API, auth, services
4. AI — Whisper, diarization, NLP
5. QA — testing, automation
6. DevOps — CI/CD, deployment, monitoring
